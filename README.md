# Система учёта технического долга

## Назначение

Приложение предназначено для учёта и оценки задач технического долга
в IT-проектах. Помогает команде понимать, какие задачи долга требуют
внимания в первую очередь, и планировать время на их исправление.

## Целевая аудитория

- тимлиды и техлиды, планирующие работу команды;
- разработчики, фиксирующие технический долг;
- менеджеры проектов, оценивающие риски.

## Предметная область

Технический долг — это накопленные в коде решения, которые замедляют
разработку и повышают стоимость поддержки: отсутствие тестов,
устаревшие библиотеки, дублирование кода, неоптимальные архитектурные
решения. Учёт долга позволяет команде осознанно управлять им.

## Основные сущности

- Проект — содержит название и описание;
- Задача долга — описание, приоритет, сложность, дата создания;
- Автор — разработчик, который зафиксировал задачу.

## Основные функции

- расчёт балла приоритета задачи долга;
- оценка времени на исправление задачи;
- определение статуса задачи по баллу и сроку.

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
