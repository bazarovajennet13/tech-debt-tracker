# Система учёта технического долга

Консольное приложение для учёта задач технического долга в IT-проектах.

## Возможности
- учёт авторов, проектов, приоритетов и задач долга;
- поиск по названию;
- фильтрация по проекту, автору, приоритету;
- сортировка задач по весу приоритета;
- закрытие и удаление задач;
- статистика (всего / закрыто / открыто);
- хранение данных в JSON.

## Сущности
- Автор
- Проект
- Приоритет
- Задача долга

## Структура проекта
- `main.py` — точка входа и меню;
- `authors.py` — работа с авторами;
- `projects.py` — работа с проектами;
- `priorities.py` — работа с приоритетами;
- `debts.py` — работа с задачами долга;
- `storage.py` — сохранение/загрузка JSON;
- `utils.py` — вспомогательный ввод;
- `data/` — JSON-файлы;
- `tests/` — автотесты.

## Требования
- Python 3.x
- pytest
- flake8
